# Home landscapes

Local backgrounds for the greeting card, bundled with Nevis for offline use. Only the current landscape is loaded.

- `morning.png`: 05:00–11:59, dawn over an alpine lake.
- `afternoon.png`: 12:00–17:59, a sunlit mountain valley.
- `evening.png`: 18:00–21:59, sunset reflected in the lake.
- `night.png`: 22:00–04:59, a moonlit mountain lake.

Times follow the device clock. Home refreshes the time each minute and when the window becomes active.
