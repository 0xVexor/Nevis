# Nevis (نسخهٔ جدید)

اپ یادداشت **فارسی‌محور (RTL)**، **آفلاین‌فرست**، با **همگام‌سازی از سرور شخصی**، روی **وب، دسکتاپ و (بعداً) موبایل**، با یک پایگاه کد و یک پیاده‌سازی از منطق داده و سینک.

این ریپو جایگزین `Nevis` قدیمی است (که فریز شده و فقط مرجع است). چرا از نو: `docs/research/` و `docs/adr/`.

## بخوانید
| فایل | چیست |
|---|---|
| [docs/VISION.md](docs/VISION.md) | هدف، غیرهدف‌ها، قیدها |
| [docs/PROCESS.md](docs/PROCESS.md) | نقش‌ها، روش کار، **فرایند تحویل کار (اگر لیمیت خوردید از اینجا ادامه دهید)** |
| [docs/STATUS.md](docs/STATUS.md) | الان کجاییم، چه چیزی را می‌توانید امتحان کنید |
| [docs/reports/](docs/reports/) | گزارش پایان هر بخش (برای ادامهٔ کار از حساب دیگر) |
| [docs/adr/](docs/adr/) | تصمیم‌ها |
| [docs/research/](docs/research/) | تحقیق‌ها |

## ساختار
```
docs/        اسناد
packages/    کتابخانه‌های TypeScript (core، editor، ...)
apps/        web (PWA)، desktop (Tauri 2)
server/      سرور Go
spikes/      آزمایش‌های کوتاه با معیار قبول و رد
```
