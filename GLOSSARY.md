# Nevis

## Language

### Decks

**Deck**
An editable collection of slides in a fixed order.

**Slide**
One authored page in a deck.

**Component**
A reusable design for part of a slide, such as a code example or callout.

**Instance**
A use of a component on a slide, with its own content and choice of variant.

**Variant**
A named form of a component, such as Compact or Annotated for a code example.

**Deck theme**
A deck's saved visual style. It defines the colors and treatments used for slide surfaces, callouts, and code blocks.

**Appearance preset**
A visual style for the Nevis workspace and note editor. A new deck can start with the current preset.

**Deck template**
A starting deck with a slide size, slide layouts, and editable sample content. It can supply its own deck theme.
