# آینهٔ Markdown (یک‌طرفه)

مبدل: `packages/bundle/src/markdown.ts` (یک پیاده‌سازی برای آینهٔ دسکتاپ و «دانلود Markdown» وب). **هرگز Markdown را پس نمی‌خواند.** fixture طلایی: `packages/bundle/test/golden/all.md` (یک تغییر مبدل = تغییر بازبینی‌شدهٔ این فایل).

| بلوک | Markdown |
|---|---|
| تیتر ۱–۳، پاراگراف، متن (پررنگ، کج، کد، خط‌خورده، زیرخط `<u>`، پیوند) | GFM |
| فهرست‌ها، تسک | `-`، `1.`، `- [x]` |
| نقل قول، کادر نکته | `>`، `> [!icon]` |
| بازشو | `<details><summary>` |
| کد، فرمول، نمودار | fenced، `$$…$$`، ` ```mermaid ` |
| جدول ساده | GFM؛ جدول با ادغام یا `dir` = HTML |
| تصویر، فایل | `![alt](attachments/<hash>)`، `[نام](attachments/<hash>)` |
| ستون‌ها | `<div class="nv-columns">` |
| بلوکی که `dir` آن با صفحه فرق دارد | `<div dir="…">` |
| پیوند صفحه | `[[عنوان]]` |
| نقاشی | کامنت `<!-- drawing -->` (**اتلاف**: تصویر نقاشی هنوز ساخته نمی‌شود) |

نام فایل `<slug عنوان>--<۸ کاراکتر آخر id>.md`؛ پوشه‌ها = درخت صفحه‌ها. front-matter: `id، title، parent، tags، created، updated، dir` و کامنت «این فایل خودکار ساخته می‌شود». دسکتاپ: Rust فقط فایل‌های تغییرکرده را اتمی می‌نویسد، فقط داخل پوشهٔ انتخاب‌شده، و فقط فایل `.md` را حذف می‌کند. اتلاف: شناسهٔ بلوک، رنگ و آیکن، `^blockId`، پایگاه‌داده (`.csv` هنوز نه).
