## قاعدهٔ هر بخش (milestone)
1. کد + آزمون خودکار + یک **دمو قابل اجرا** با دستور مشخص.
2. بخش در `docs/STATUS.md` به‌روز می‌شود (چه چیزی را چطور امتحان کنید).
3. **گزارش پایان بخش** در `docs/reports/NN-نام.md` نوشته می‌شود (قالب پایین).
4. commit (پیام واضح). هر بخش یک تگ: `m1`, `m2`, ...
5. مالک امتحان می‌کند؛ بخش بعدی بعد از آن.

## قالب گزارش پایان بخش (برای ادامه از حساب دیگر)
هر گزارش باید خودکفا باشد؛ کسی که هیچ گفت‌وگویی را ندیده فقط با این فایل‌ها ادامه بدهد.
```
# گزارش NN: نام
- تاریخ، commit، تگ
- هدف این بخش و آنچه واقعاً انجام شد
- چه چیزی کار می‌کند (با دستور اجرا و آزمون)
- چه چیزی کار نمی‌کند یا آزموده نشده (صادقانه)
- تصمیم‌های گرفته‌شده و چرا (لینک ADR)
- فایل‌های کلیدی
- مشکلات و ریسک‌های باز
- قدم بعدی دقیق (دستور و فایل‌ها)
- چگونه ادامه دهم: دستورهای نصب/اجرا/آزمون از صفر
```
