# زبان طراحی (Design Language)

> **v6 «Calm» جایگزین این سند است.** قواعد، توکن‌ها و کامپوننت‌های جدید در [design-system.md](design-system.md) (انگلیسی) و صفحه‌ی زنده‌ی [design-system/index.html](design-system/index.html) هستند. هر ویژگی تازه باید طبق آن ساخته شود؛ این سند فقط تاریخچه‌ی ظاهر قدیمی است.

> **v4 — «Aurora Paper» (فعلی).** UI از صفر بازطراحی شد؛ بخش‌های قدیمی‌تر این سند فقط تاریخچه‌اند.
> - استایل‌ها در `spike/tiptap/src/styles/` هستند (`tokens → base → shell → page → editor → overlays → views → print`) و از `src/index.css` import می‌شوند. `App.css` و `home.css` حذف شدند.
> - **توکن‌ها** با `light-dark()` فقط یک‌بار تعریف می‌شوند؛ تم از `color-scheme` می‌آید (سیستم، یا `data-theme` روی `<html>`).
> - **رنگ**: یک `--accent`؛ `--accent-2` با `oklch(from … h+52)` از آن مشتق می‌شود و `--grad` را می‌سازد، پس تغییر رنگ تأکید در تنظیمات کل اپ را بازرنگ می‌کند.
> - **ساختار**: سایدبار شناور (شیشه‌ای) + برگه‌ی اصلی شناور روی بوم «شفق» با شبکه‌ی نقطه‌ای؛ ردیف فعال با نوار گرادیانی؛ دکمه‌های اصلی گرادیانی با درخشش؛ کاشی‌های آیکون squircle؛ حرکت با `--ease`/`--spring` و احترام به «کاهش حرکت».
> - جهت‌ها: گرادیان‌ها با `--to-end` و ویژگی‌های منطقی، پس RTL/LTR هر دو درست‌اند.


مرجع: تصاویر طراحی (Nexar / Muse / Nexora / Nova). همه‌ی UI جدید باید با این قواعد هماهنگ باشد.
قانون کار: **فقط ظاهرِ فیچرهای موجود** طراحی شود؛ فیچر جدید (Inbox، Share، AI، داشبورد، تنظیمات، کاور و…) فقط وقتی ساخته می‌شود که صریحاً خواسته شود.

## اصول
- تیره‌ی تقریباً سیاه با رنگ خنثی، و روشن با سطح‌های سفید؛ مرزها فقط 1px کم‌رنگ، بدون سایه‌ی سنگین.
- ساختار: سایدبار **تخت** روی پس‌زمینه‌ی اپ + یک **پنل اصلی** گرد با حاشیه‌ی باریک (`.main`).
- سطح‌های بالا آمده (کارت، دکمه‌ی ثانویه، فیلد جست‌وجو): `--bg-raised` + حاشیه `--border` + شعاع `--radius`.
- رنگ تأکید (`--accent`) فقط برای وضعیت فعال/فوکوس/دکمه‌ی اصلی؛ بقیه خنثی.
- آیکون‌ها outline و یک‌دست (`icons.tsx`)؛ ایموجی صفحه داخل جعبه‌ی گرد با حاشیه (`.page-icon`).
- سرتیتر بخش‌ها (`.section`) کوچک، کم‌رنگ و قابل جمع‌شدن با chevron.
- منو/پاپ‌اور/مودال: `--pop` + حاشیه + `--shadow`، مودال با backdrop تیره.
- نوار ابزار شناور (`.bubble`) شبیه toolbar عکس‌ها: ردیف فشرده‌ی دکمه‌ها با جداکننده.

## توکن‌ها (`src/index.css`)
| توکن | کاربرد |
|---|---|
| `--bg-app` | پس‌زمینه‌ی پنجره |
| `--bg` | پنل اصلی |
| `--bg-raised` | کارت/فیلد/دکمه |
| `--pop` | منو و مودال |
| `--border`, `--hover`, `--active` | خطوط و حالت‌ها |
| `--accent`, `--accent-bg`, `--accent-ring` | تأکید (از `--accent` مشتق می‌شوند) |
| `--radius-sm/--radius/--radius-lg` | 8 / 12 / 16 |

## آماده برای آینده
تنظیمات ظاهر (مثل عکس Settings → Appearance) فقط باید متغیرهای `:root` را عوض کنند:
- رنگ تأکید: `--accent` (بقیه‌ی رنگ‌های تأکید از آن می‌آیند)
- گوشه‌ها: `--radius*`
- پس‌زمینه: `--app-bg-image`
- تم: `data-theme="light|dark"` روی `<html>` (بدون مقدار = تبعیت از سیستم)
- سبک سایدبار (Default / Compact / Icons only) و حرکت کمتر: با کلاس روی `.app` اضافه شود.

## الگوهای برنامه‌ریزی‌شده (هنوز ساخته نشده)
Home با کارت‌های «اخیر/سنجاق‌شده»، کاور صفحه، toolbar ثابت ادیتور، پنل کناری Style/Insert/AI، صفحه‌ی Settings با تب‌ها، ردیف کاربر در پایین سایدبار، دکمه‌ی Share.

## به‌روزرسانی: تطبیق با مرجع‌ها (Nexar / Muse / Nexora)
- **کاور**: درون‌چیده و گرد (حاشیه ۱۲px)، دکمه‌ی «تغییر کاور» همیشه بالا-کنار؛ جعبه‌ی آیکون ۵۶px نیمه‌روی لبه‌ی کاور.
- **نوار ابزار ثابت** (`Toolbar.tsx`) بالای ادیتور: بلوک، H1–H3، B/I/U/S، لیست‌ها، نقل‌قول، لینک، کد، جهت، undo/redo؛ تک‌خط با اسکرول افقی.
- **آیکون صفحه‌ها** (`PageIcon.tsx`): ایموجی، وگرنه کاشی رنگی با آیکون outline (رنگ از id).
- **سایدبار**: متن ۱۳px، سرتیتر ۱۱px، دکمه‌ی «صفحه جدید» پایین. سبک‌ها با `data-side=compact|icons` و افکت شیشه‌ای با `data-glass`.
- **اقدام سریع**: فقط آیکون (۳×۲)، برچسب در tooltip.
- **تنظیمات**: سربرگ کارت، سبک نوار کناری (segmented)، سوییچ‌ها (شیشه‌ای، نمایش کاور، نمایش آیکون صفحه)، ستون پیش‌نمایش با انتخاب فونت و «کاهش حرکت».
- سوییچ‌های ظاهری همه به‌صورت `data-*` روی `<html>` اعمال می‌شوند (`settings.ts → apply`).

## دو زبانه (i18n)
- رابط به‌صورت پیش‌فرض **انگلیسی و چپ‌به‌چپ (LTR)** است؛ از «Settings → Language» می‌شود فارسی (RTL) را انتخاب کرد. جهت چیدمان را هم می‌شود جدا تعیین کرد (Auto / LTR / RTL).
- متن‌ها با `t('English text', { vars })` از `src/i18n.ts` می‌گذرند؛ ترجمه‌ی فارسی در `src/fa.ts` است. متنی که ترجمه نداشته باشد انگلیسی نشان داده می‌شود.
- ثابت‌های سطح ماژول (برچسب‌ها) کلید انگلیسی ساده نگه می‌دارند و هنگام نمایش `t()` می‌شوند.
- جهت از `<html dir>` می‌آید؛ CSS باید از ویژگی‌های منطقی (`inline-start/end`) استفاده کند. چرخش chevron‌ها با `:root[dir='rtl']` است.
- **محتوای صفحه‌ها هیچ‌وقت ترجمه نمی‌شود**؛ جهت هر پاراگراف مستقل است (bidi).

## زبان طراحی v2 (مرجع‌های Nexi / Nexora) — از این به بعد معیار است
مرجع: تصاویر Nexora (سفید و هوادار، حاشیه‌ی ۱px، یک رنگ تأکید ایندیگو). اجرا در بخش «design language v2» انتهای `App.css`.
- **رنگ**: سطح‌ها سفید خالص (`--bg`, `--bg-raised`)، پس‌زمینه‌ی اپ `#f4f5fa` با گرادیان بسیار کم‌رنگ؛ تأکید `#5b57f0` (تیره: `#6c68f5`). توکن‌های تازه: `--accent-soft` (پس‌زمینه‌ی callout)، `--ok` (تیک موفقیت).
- **سایدبار**: لوگوی مربع تیره، ردیف فعال با پس‌زمینه‌ی `--accent-bg` و متن/آیکون تأکید، دکمه‌ی «صفحه جدید» پر (accent).
- **دکمه‌ی اصلی** (Export، New page، `.primary`): accent پر، شعاع ۱۰px. دکمه‌ی ثانویه: سفید + حاشیه. خطرناک: متن قرمز، hover با تینت قرمز.
- **کاور**: دکمه‌های سفید «Change cover / Remove» با آیکون در گوشه‌ی بالا؛ جعبه‌ی آیکون ۷۲px سفید با سایه روی لبه‌ی کاور؛ عنوان ۴۰px.
- **تگ/وضعیت**: تگ = چیپ ۸px با تینت accent؛ وضعیت = pill با chevron و در حالت انتخاب، تینت رنگ همان وضعیت.
- **نوار ابزار**: دکمه‌ی «+» پر (accent) در ابتدا؛ بقیه‌ی دکمه‌ها خنثی، حالت فعال تینت accent.
- **منوی `/`**: ۳۴۰px، ردیف ۴۰px با آیکون outline در مربع حاشیه‌دار ۳۰px، عنوان + توضیح هم‌خط (کم‌رنگ)، انتخاب‌شده = تینت accent. آیکون آیتم‌ها در لیست‌ها به‌صورت `i:name` نوشته می‌شود (`editor/menuIcons.ts`)، نه ایموجی/گلیف.
- **منو/پاپ‌اور**: شعاع ۱۲px، آیتم ۸px با hover ملایم. **جست‌وجو**: آیکون صفحه در مربع حاشیه‌دار + زمان آخرین ویرایش در انتهای ردیف.
- **Toast**: کارت سفید با تیک سبز (نه نوار تیره). **Callout**: پس‌زمینه‌ی `--accent-soft` با لبه‌ی accent.
- **دسترس‌پذیری** (از اسکیل ui-ux-pro-max): focus ring دیده‌شونده روی کنترل‌ها، آیکون‌های ساختاری SVG با stroke یکسان.
- فیچرهایی که در مرجع هست ولی هنوز ساخته نشده (Home، Inbox، Share، Kanban، Calendar، AI، ردیف کاربر) طبق قانون بالا ساخته نشدند.

### v3 — چیدمان تخت مثل Nexora (جایگزین «پنل گرد شناور»)
- **پیش‌فرض روشن** است (مرجع‌ها روشن‌اند)؛ تیره با دکمه‌ی خورشید/ماه یا Settings.
- سایدبار روی پنجره و بدون کارت، خط جداکننده‌ی ۱px؛ ناحیه‌ی محتوا سفید و تمام‌صفحه (بدون گوشه‌ی گرد/سایه). «Settings» زیر جست‌وجو، «Trash/Data & backup/New folder» بعد از درخت، «New page» پایین.
- نوار ابزار: «+» تیره، دکمه‌های تصویر/جدول/لینک‌صفحه؛ جداکننده‌ها فقط فاصله‌اند. چک‌باکس گرد با تیک accent. «Add tag…» به‌شکل pill حاشیه‌دار.
- پنل کناری (Quick actions/Outline/Navigation) به‌صورت پیش‌فرض بسته است.
