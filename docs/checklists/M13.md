# چک‌لیست مالک: M13 (snapshot، purge، هرس)

| # | محیط | گام | انتظار | نتیجه |
|---|---|---|---|---|
| 1 | سرور شخصی | **پیش از هر چیز یک بکاپ دستی** (`DATA_DIR/backup` را ببینید؛ سرور روزی یک بار قبل از هرس می‌گیرد) | فایل `nevis-….db` هست | |
| 2 | وب + دسکتاپ | صفحه‌ای را حذف و در سطل «حذف دائمی» کنید | در هر دو دستگاه می‌رود؛ بعد از reload برنمی‌گردد | |
| 3 | دستگاه تازه | با workspace واقعی بزرگ وارد شوید؛ زمان شروع را بنویسید (iPhone هم) | سریع‌تر از قبل؛ **عدد را بنویسید** | |
