# چک‌لیست مالک: M6 (دسکتاپ Tauri)

پیش‌نیاز: Rust (`rustup`)، Xcode command line tools، و برای Windows: WebView2 و MSVC. یک سرور Go که از Mac شما دیده شود (برای دمو: `server/scripts/demo.sh` → `http://localhost:8788`؛ **آدرس سرور در اپ دسکتاپ باید `http://` یا `https://` با میزبان و پورت باشد**، مثل `http://localhost:8788`).

اجرا (از ریشهٔ ریپو):
```bash
corepack pnpm install
corepack pnpm --filter web build
cd apps/desktop/src-tauri && cargo build --features custom-protocol && ./target/debug/nevis-desktop
```
(یا برای توسعه: `corepack pnpm --filter @nevis/desktop tauri dev` که vite را روی ۵۱۷۴ لازم دارد.)
داده: `~/Library/Application Support/app.nevis.desktop/` (macOS)، `%APPDATA%\app.nevis.desktop\` (Windows)، یک فایل `ws-<id>.sqlite` برای هر workspace و `config.json`. **نتیجهٔ دستگاه را فقط خودتان بنویسید.**
