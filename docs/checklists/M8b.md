# چک‌لیست مالک: M8b (اپ کامل با ظاهر و حس اپ قدیمی)

اجرا: `server/scripts/demo.sh` → http://localhost:8788 (یا دسکتاپ، یا iPhone روی HTTPS). **نتیجه را فقط خودتان بنویسید**؛ مهم‌ترین بخش «همان حس اپ قدیمی» است: **فهرست تفاوت‌هایی که می‌بینید را همین‌جا بنویسید** (ما نمی‌توانیم «حس» را خودکار بسنجیم).

| # | محیط | گام | انتظار | نتیجه / تفاوت با اپ قدیمی |
|---|---|---|---|---|
| 1 | Safari macOS | ظاهر کلی: نوار کنار، خانه، رنگ‌ها، فونت، فاصله‌ها | شبیه اپ قدیمی (طراحی «Aurora Paper» کپی شده) | |
| 2 | Safari macOS | خانه ← صفحهٔ تازه ← نوشتن ← درخت صفحه‌ها ← زیرصفحه، بالا/پایین، تورفتگی | درست | |
| 3 | Safari macOS | ⌘K: جست‌وجوی صفحه (با «ك» عربی)، دستورها، Alt+N | کار می‌کند؛ با کیبورد فارسی هم | |
| 4 | Safari macOS | تنظیمات: تم تیره، اندازهٔ متن، رنگ تأکید، عرض نوار کنار؛ بعد reload | روی همین دستگاه می‌ماند؛ **در دستگاه دیگر عوض نمی‌شود** | |
| 5 | Mac و iPhone | تنظیمات همگام (تقویم، اول هفته) را در یکی عوض کنید | در دیگری هم عوض می‌شود | |
| 6 | Safari macOS | پایگاه‌داده: نمای جدول، مرتب‌سازی، پنهان کردن ستون، نمای برد با کشیدن کارت | کار می‌کند | |
| 7 | Safari macOS | قالب‌ها (جلسه، کارها، روزانه)؛ سطل زباله و بازگردانی؛ «همهٔ صفحه‌ها» با جست‌وجو | کار می‌کند | |
| 8 | iPhone (Home Screen، HTTPS) | همهٔ بالا با لمس: منوی کشویی، صفحه‌نوشتن، تنظیمات، برد (منوی «انتقال به» روی کارت) | قابل استفاده؛ **بنویسید** چه چیزی بد است | |
| 9 | دسکتاپ | همان ۲ تا ۷ | مثل وب | |
| 10 | هر دستگاه | چیزی از اپ قدیمی که **دیدید و نیست** (آیکن صفحه، کاور، برچسب، فلش‌کارت، گراف، ...) | فهرست بنویسید؛ «نیامده‌ها» در گزارش ۱۱ است | |
