# چک‌لیست مالک: M9 (پیوست‌ها)

اجرا: `server/scripts/demo.sh` → http://localhost:8788 (و دسکتاپ). نتیجه را فقط خودتان بنویسید.

| # | محیط | گام | انتظار | نتیجه |
|---|---|---|---|---|
| 1 | وب، Chrome | صفحهٔ تازه ← `/` ← «تصویر» ← یک عکس واقعی (۲–۵MB) | بلافاصله نشان داده می‌شود | |
| 2 | وب | همان صفحه را **آفلاین** کنید (حالت هواپیما)، دو تصویر دیگر بکشید/انتخاب کنید | تصاویر دیده می‌شوند؛ بالای صفحه «فایل‌ها: n در انتظار» | |
| 3 | وب + دسکتاپ | وب را آنلاین کنید؛ در **دسکتاپ** همان صفحه را باز کنید | تصاویر در دسکتاپ می‌آیند (ممکن است چند ثانیه «هنوز نرسیده» باشد) | |
| 4 | Safari macOS و iPhone | یک تصویر ۲۰–۵۰MB یا چند تصویر؛ خودتان ببینید خطا «جای ذخیره پر است» می‌دهد یا نه | **این همان ناشناختهٔ اصلی است؛ نتیجه را بنویسید** | |
| 5 | هر دستگاه | یک PDF با `/` ← «فایل»؛ روی کارت بزنید | با همان نام دانلود می‌شود و باز می‌شود | |
| 6 | هر دستگاه | کشیدن تصویر از Finder به صفحه (دسکتاپ و Chrome)، paste تصویر از clipboard | کار می‌کند | |
| 7 | هر دستگاه | نقاشی بسازید و ذخیره کنید؛ در دستگاه دیگر باز کنید | همان نقاشی؛ ویرایش دوباره ممکن | |
| 8 | تنظیمات | بخش «فضای ذخیره‌سازی حساب» | عدد مصرف و سهمیه درست است | |
| 9 | iPhone | همهٔ بالا با لمس | قابل استفاده؛ بنویسید چه بد است | |
