# چک‌لیست مالک: M8a (ادیتور کامل)

اجرا: `server/scripts/demo.sh` → http://localhost:8788؛ در نوار کنار «نمونهٔ همهٔ بلوک‌ها». **نتیجهٔ دستگاه را فقط خودتان بنویسید.**

| # | محیط | گام | انتظار | نتیجه (✓/✗ + توضیح) |
|---|---|---|---|---|
| 1 | Safari macOS | «نمونهٔ همهٔ بلوک‌ها» | همهٔ بلوک‌ها دیده می‌شوند: فرمول، نمودار، کد رنگی، جدول، ستون‌ها، کادر نکته، بازشو | |
| 2 | Safari macOS | در هر بلوک متن فارسی بنویسید؛ جهت (←/→ در نوار شناور)؛ undo (⌘Z) | درست؛ بدون حرف گم یا تکراری | |
| 3 | Safari macOS | IME فارسی (کیبورد فارسی سیستم) درون کادر نکته، جدول و ستون | composition قطع نمی‌شود | |
| 4 | Safari macOS | `/` بزنید و هر بلوک را از منو بسازید | منو باز می‌شود؛ بلوک ساخته می‌شود | |
| 5 | Safari macOS | `[[` و نام یک صفحه | پیوند به صفحه؛ کلیک می‌رود به آن صفحه | |
| 6 | Safari macOS | از **Word** یک متن با فهرست و جدول و یک تصویر paste کنید | متن و ساختار می‌آید؛ تصویر به «جای تصویر» تبدیل می‌شود (پیوست‌ها M9) | |
| 7 | Safari macOS | از یک **چت AI** (ChatGPT/Claude) یک پاسخ Markdown کپی و paste کنید (فهرست، جدول، کد، فرمول `$$..$$`، نمودار mermaid) | همه به بلوک مناسب تبدیل می‌شود | |
| 8 | Chrome و Firefox | همان ۶ و ۷ (در Firefox آزمون خودکار paste ممکن نبود) | | |
| 9 | Safari macOS | نقاشی: «ویرایش نقاشی»، چند شکل و متن فارسی بکشید، ذخیره | پیش‌نمایش روی صفحه؛ متن فارسی با فونت درست | |
| 10 | iPhone (PWA) | همان صفحه | قابل استفاده؛ **بنویسید** کدام بلوک‌ها در لمس بد است (منوی `/`، نوار شناور، دستگیرهٔ جابه‌جایی) | |
| 11 | Mac و iPhone | هر دو آفلاین؛ در یکی کادر نکته و در دیگری جدول را ویرایش کنید؛ وصل کنید | هر دو ویرایش در هر دو هست | |
| 12 | دسکتاپ | همان صفحه | مثل وب | |
