# چک‌لیست مالک: M5 (یادداشت فارسی در وب، آفلاین، دو دستگاه)

اجرا: `server/scripts/demo.sh` → http://localhost:8788 (برای iPhone روی HTTPS: `docs/dev-https.md`). **نتیجهٔ دستگاه را فقط خودتان بنویسید.**

| # | محیط | گام | انتظار | نتیجه (✓/✗ + توضیح) |
|---|---|---|---|---|
| 1 | Safari macOS | ورود، «فضای کار تازه»، «صفحهٔ تازه»، عنوان فارسی و چند خط متن فارسی/انگلیسی/ارقام | متن درست و راست‌به‌چپ؛ نشانگر «ارسال‌نشده» به ۰ می‌رسد | |
| 2 | Safari macOS | تایپ فارسی با IME (کیبورد فارسی سیستم)، حذف و ویرایش وسط کلمه | هیچ حرفی تکراری یا گم نمی‌شود | |
| 3 | Safari macOS | reload | همهٔ صفحه‌ها و متن برمی‌گردد | |
| 4 | iPhone (Home Screen، HTTPS) | ورود با همان حساب | صفحه‌های Mac دیده می‌شوند | |
| 5 | Mac و iPhone | تایپ در Mac؛ نگاه به iPhone | متن حدود ۱ ثانیه بعد دیده می‌شود | |
| 6 | iPhone | حالت هواپیما؛ ویرایش یک صفحه؛ در Mac هم همان صفحه را ویرایش کنید؛ حالت هواپیما را بردارید | هر دو ویرایش در هر دو دستگاه هست و دو متن یکسان است (≤ ۵ ثانیه) | |
| 7 | iPhone | وسط تایپ برنامه را swipe-up ببندید؛ دوباره باز کنید | حداکثر ~۳۰۰ms آخر از دست می‌رود | |
| 8 | هر دو | زیرصفحه، تغییر نام، حذف به سطل، بازگردانی | همه‌جا یکسان | |
| 9 | iPhone | نتیجهٔ **آزمون ۷ روزهٔ M3** (`docs/checklists/M3.md`) | داده هنوز هست؟ تاریخ و نتیجه را بنویسید | |
| 10 | هر دو | مشکل IME یا جهت متن (اگر دیدید) | شرح دقیق (دستگاه، کیبورد، گام‌ها) | |
