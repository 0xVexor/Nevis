# چک‌لیست مالک: M11 (فلش‌کارت و تاریخچه)

| # | محیط | گام | انتظار | نتیجه |
|---|---|---|---|---|
| 1 | وب | صفحه با چند بلوک «بازشو» (`/بازشو`)، عنوان = پرسش، محتوا = پاسخ؛ نوار کنار ← فلش‌کارت | هر بازشو یک کارت؛ شمارندهٔ خانه | |
| 2 | وب + دسکتاپ | هر دو را آفلاین کنید؛ هر دو همان کارت را مرور کنید؛ وصل کنید | هر دو مرور در هر دو دستگاه؛ برنامهٔ مرور یکسان | |
| 3 | وب | یک صفحه: «ذخیرهٔ نسخه»، متن را عوض کنید، ساعت بالا ← بازگرداندن | متن قدیمی برمی‌گردد؛ نسخهٔ «قبل از بازگردانی» هست | |
| 4 | دستگاه دوم | همان صفحه بعد از بازگردانی | متن بازگردانده‌شده را می‌بیند | |
| 5 | هر دستگاه | **ظاهر فلش‌کارت و تاریخچه را با اپ قدیمی مقایسه کنید** | تفاوت‌ها را بنویسید | |
