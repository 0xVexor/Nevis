# Slide design controls

Use the Forest & Lime Spring carousel as the first design target. The deck editor should make it possible to assemble the carousel by choosing a theme, selecting layouts, and switching component variants.

- A deck theme defines typography, spacing, colors, and shared component styles.
- A layout provides editable regions for a code walkthrough, a diagram with explanation, or a side-by-side comparison.
- Code panels and callouts support variants. Switching a variant preserves the instance's text and attachments.
- Decks keep their saved appearance when reopened. The editor and PDF use the same theme, layout, and variant selections.

Review the rebuilt carousel in the editor and in exported PDFs at portrait and widescreen sizes. Check that each slide fits and that code and diagrams remain readable.
