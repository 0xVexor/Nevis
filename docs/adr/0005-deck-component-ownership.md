# Keep live component links within a deck

Editing a component updates its linked instances in the same deck. Each instance owns its content and choice of variant, so changing the component's design preserves the material on each slide. A component copied into another deck belongs to that deck. This keeps a previously published deck independent of later design changes elsewhere.

Each deck owns its theme. Changing a named color updates the elements linked to that color in the deck. A slide element can also use a color of its own.
