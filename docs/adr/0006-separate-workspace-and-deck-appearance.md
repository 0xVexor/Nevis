# Share visual presets between the workspace and decks

The workspace uses an appearance preset and can follow the system color scheme. A new deck takes a fixed light or dark theme from that appearance unless its template supplies a theme. Decks use the saved theme in the editor and print renderer so switching the workspace appearance leaves their output stable.

Saved theme identifiers keep their palette meanings. A redesigned palette needs a new identifier so it does not silently restyle existing decks.
