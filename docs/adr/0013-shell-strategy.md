# ADR-0013: پوسته‌ها — PWA، دسکتاپ Tauri، موبایل

- وضعیت: **تصمیم‌شده** برای وب و دسکتاپ؛ **باز تا spike M16** برای موبایل
- اطمینان: ۸۰٪ (وب/دسکتاپ)؛ ۵۰٪ برای گرایش پیش‌فرض موبایل
- تاریخ: 2026-11-20
- مرتبط: ADR-0001، ADR-0007؛ تحقیق: R3 (همه)، R2 §6-7

## زمینه
- وب (PWA) و دسکتاپ اول؛ موبایل بعداً؛ یک کد UI و یک هسته.
- Tauri 2 دسکتاپ بالغ است و اپ قدیمی روی آن است. Tauri موبایل: اپ تولیدی معتبری پیدا نشد؛ باگ کیبورد iOS (#9907) باز است؛ updater موبایل ندارد؛ Service Worker روی `tauri://` در iOS کار نمی‌کند (R3 §1، §3).
- Capacitor 8 بالغ‌تر است و Logseq موبایل با آن ساخته شده (R3 §2)؛ ولی یعنی شکل سوم آداپتور store و کوریر.

## تصمیم
1. **وب = PWA** با Vite، same-origin روی سرور Go (`WEB_DIR`). Service Worker فقط برای cache پوستهٔ اپ (offline load)، نه برای سینک (Background Sync در Safari نیست؛ R2 §6). به‌روزرسانی SW: پیام «نسخهٔ تازه»، و اجبار reload وقتی سرور `426` داد.
   - مالک باید بداند: در Safari iOS فقط نسخهٔ «Add to Home Screen» احتمال ماندگاری بهتری دارد؛ تب معمولی Safari ممکن است بعد از ۷ روز بی‌استفاده پاک شود (تأییدنشده، آزمون S6 در M3).
2. **دسکتاپ = Tauri 2** (macOS و Windows اول؛ Linux بهترین‌تلاش به دلیل WebKitGTK). همان bundle وب + آداپتور store-tauri + Net از Rust. `use_https_scheme` **ثابت** می‌ماند و هرگز عوض نمی‌شود (هرچند داده در SQLite است، تنظیمات WebView به origin وابسته‌اند). updater رسمی Tauri با امضا.
3. **موبایل: تصمیم در M16** (بعد از نسخهٔ اول وب/دسکتاپ، مگر مالک زودتر بخواهد). spike هر دو گزینه را با **همان bundle وب** روی iPhone واقعی و یک Android می‌سنجد:
| معیار | قبول |
|---|---|
| تایپ فارسی با IME، caret و composition | مثل Safari |
| کیبورد روی ادیتور (viewport، #9907) | ادیتور زیر کیبورد نرود |
| SQLite بومی + آداپتور store و conformance | سبز |
| کوریر پس‌زمینه (اگر مالک خواست) قابل ساخت | نمونهٔ کار‌کرده با `BGAppRefreshTask` |
| اندازه و زمان شروع | شروع < ۲s روی iPhone میان‌رده |
| انتشار در App Store/Play (2.1(a) demo، 5.1.1(v) حذف حساب) | مسیر مستند |
   - **گرایش پیش‌فرض: Tauri 2 موبایل**، چون آداپتور SQLite، Net، keychain و کوریر Rust با دسکتاپ مشترک‌اند. **اگر** IME/کیبورد یا SQLite در spike رد شد → **Capacitor 8** با `@capacitor-community/sqlite` (آداپتور store سوم و کوریر Swift/Kotlin یا Background Runner).
   - شرط‌های از الان (ارزان): هسته بدون DOM؛ store پشت رابط؛ ترابری جدا از اعمال (ADR-0007)؛ UI واکنش‌گرا و لمسی در طراحی M8.
4. **اپ‌استور و سرور شخصی:** داور اپل حساب demo روی سرور در دسترس لازم دارد (R3 §6)؛ تصمیم مالک (OPEN-QUESTIONS).

## پیامدها
- تا M16 هیچ کد موبایل نوشته نمی‌شود؛ فقط قیدها رعایت می‌شوند.
- PWA روی iPhone تا آن زمان تنها راه موبایل است.

## چه چیزی تصمیم را برمی‌گرداند
- اگر مالک موبایل را زودتر خواست: M16 بلافاصله بعد از M9 جابه‌جا می‌شود.
- اگر Tauri در spike رد شد: Capacitor (بالا).
