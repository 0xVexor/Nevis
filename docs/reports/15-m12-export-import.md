# گزارش 15: M12 — export/import، آینهٔ Markdown، import دادهٔ قدیمی

- تاریخ: 2026-11-21 · تگ: `m12`
- وضعیت: **بخش خودکار سبز.** import دادهٔ **واقعی** مالک اجرا نشده (دادهٔ او در دسترس نیست)؛ چک‌لیست مالک.

## ساخته‌شده
- `packages/bundle`: باندل `*.nevis.zip` (fflate، قالب: `docs/formats/bundle-v1.md`)، import با اعتبارسنجی هش، مبدل Markdown با fixture طلایی (`docs/formats/markdown-mirror.md`)، import قدیمی (`docs/formats/legacy-import.md`، دستور `pnpm nevis import-legacy`).
- اپ: تنظیمات ← «دانلود باندل» و «دانلود Markdown (zip)»؛ فهرست workspace ← «ورود از باندل» (همیشه workspace تازه).
- دسکتاپ: آینهٔ یک‌طرفه: دستور Rust `mirror_sync` (نوشتن اتمی، فقط فایل‌های تغییرکرده، فقط داخل پوشه، حذف فقط `.md`)؛ در Settings دسکتاپ پوشه را می‌نویسید؛ ۵ ثانیه بعد از هر تغییر فایل‌های همان صفحه بازنویسی می‌شود.

## نتایج (اجرا شده)
| معیار | نتیجه |
|---|---|
| round-trip باندل | export ← import ← export: همهٔ فایل‌ها یکسان (به‌جز `exportedAt`/`workspace`/`app`) |
| باندل خراب، فایل غیر zip، workspace غیرتازه | رد با پیام روشن (آزمون) |
| ingest ۱۰k صفحه < ۶۰s | **import ۰٫۸s، export ۱٫۰s** (MemoryStore؛ فقط هزینهٔ CPU: unzip، اعتبارسنجی، ساخت ۱۰k Y.Doc، ۲۰k op). زمان با IndexedDB واقعی سنجیده نشده؛ چک‌لیست |
| آینه فقط فایل تغییرکرده را بازنویسی می‌کند | Rust: بار دوم `skipped`؛ مسیر خارج از پوشه رد؛ فایل غیر `.md` هرگز حذف نمی‌شود؛ بدون فایل temp (۲ آزمون Rust) |
| e2e در اپ واقعی | صفحه با متن فارسی/انگلیسی و تصویر ← باندل دانلود و محتوا ← Markdown دانلود و front-matter ← import در مرورگر دوم به workspace تازه: صفحه، عنوان، متن، تصویر (بایت پیوست) هست |
| import قدیمی | آزمون با vault ساختگی: نگاشت callout/layout/drawing/pageLink/null، گزارش اتلاف و ردشده‌ها، و باندل خروجی import می‌شود |
| کل | `pnpm check` exit 0؛ bundle ۷ آزمون؛ Playwright Chromium ۴۲ سبز؛ دسکتاپ `test:ui` سبز؛ `cargo test` ۱۷ |

## محدودیت‌ها
- **import واقعی مالک انجام نشد.** نگاشت قدیمی بر اساس مدل `Page` قدیمی و تبدیل‌های M8a نوشته شده؛ پیوست‌های قدیمی (blob قدیمی) و ردیف‌های پایگاه‌داده قدیمی نمی‌آیند.
- ZIP استریم نیست؛ پیوست بسیار بزرگ حافظه می‌خورد.
- آینه: پوشه با متن وارد می‌شود (دیالوگ انتخاب پوشه نصب نیست)؛ نقاشی در Markdown کامنت است؛ آینهٔ دسکتاپ در UI واقعی خودکار آزموده نشد (فقط Rust و مبدل).
- پایگاه‌داده export CSV ندارد (فقط در باندل).
