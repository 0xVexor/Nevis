# Nevis 1.1.0 beta 16

A prerelease for testing. To receive beta updates, enable **Receive pre-release updates** in **Settings → About → Updates**.

## Slide decks

- Create editable decks from the sidebar or start with the Technical carousel, Short lesson, or Project briefing template.
- Arrange content in columns and add code blocks, reusable callouts, Mermaid diagrams, and images.
- Choose one slide size for the deck. Use portrait, square, widescreen, tall, or custom dimensions.
- Print or save a deck as a PDF. On macOS, MCP can export the saved deck directly to a PDF.
- Use MCP to find, read, create, and edit decks, including inserting, replacing, reordering, and resizing slides.
