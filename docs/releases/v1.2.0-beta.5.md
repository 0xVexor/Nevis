# Nevis 1.2.0 beta 5

Windows and universal macOS beta installers using https://nevis.manaz.pro.

- Downloading a workspace starts with a fresh local baseline, including when the same destination folder is reused.
- A file missing from the local folder is not enough to delete its server copy automatically. Deletions explicitly recorded by Nevis continue to sync. Other missing files wait for the person's confirmation.
- Baselines belong to the local folder. Moving or downloading a workspace into a different folder cannot reuse the old folder's deletion history.
- Existing safeguards stop deletion after transfer errors, preserve concurrent edits and hold large or empty-side deletions for confirmation.

Regression tests reproduce fresh-folder and missing-file cases. Sync tests and the client/server test suite are run before release. Recovering files removed with earlier versions is a separate operation; installing this version does not automatically restore them.

Enable sync for each workspace. Automatic sync runs for the currently open workspace. Sign in on another device and download into a new empty folder. Close other running copies of Nevis before testing.

This is a beta release. Keep a local workspace backup while evaluating sync.
