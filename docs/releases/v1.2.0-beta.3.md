# Nevis 1.2.0 beta 3

Beta installers for Windows and macOS with the Nevis sync client.

- The default sync server is https://nevis.manaz.pro.
- Create an account using an invitation, then enable sync separately for each workspace.
- Sync runs automatically for the workspace currently open while the application is running.
- On another device, sign in to the same account and download the workspace into a new folder.

Keep a backup of your workspace while testing this beta. Cross-device sync on the public server is still under evaluation. Close any other running copy of Nevis before opening this version.

This release uses the beta update channel. Windows provides a setup executable. The macOS installer supports Apple Silicon and Intel Macs.
