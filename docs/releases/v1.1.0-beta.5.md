# Nevis 1.1.0 beta 5

A pre-release for testing. It is not offered as an update unless **Receive pre-release updates** is turned on in Settings → About → Updates.

## What's new

Everything in 1.1.0 beta 4, plus:

- **Import and backup, rebuilt.** Settings → Data & backup is now three clear parts: import or restore, export and backup, and automatic backup (with its status right there, no separate window).
- **Import with a review step.** Pick or drop Markdown files, an Obsidian folder, a zip you exported or a backup file. Before anything is written you see what is in it (pages, folders, images, what will be left out). Progress is a bar, and a file that cannot be read is named with the reason while the rest still import.
- **Restore a zip.** The zip from "Export" can now be imported back. It is added as a new folder; nothing you have is replaced.
- **Safer restore.** A backup is checked completely first and the review shows its date, size and how many pages it will replace. In the browser a copy of your current notes is saved to your downloads before anything is replaced, and the restore stops if that copy cannot be made.
- **Two fonts.** Choose one font for Persian and Arabic letters and another for English. Each applies everywhere in the app, and a Persian font no longer changes how English words look (and the reverse, including the system font choice).
- **A picture for every `/` command.** The command menu shows a small sample of what the highlighted command writes, beside the menu, like Notion.
- **Find in page.** The `Ctrl F` bar looks like the main search, sits in the middle under the top bar and no longer collides with the editor toolbar.
- **Search (`Ctrl K`).** The header of an empty search no longer collapses.
- **Connect an AI app.** A write whose letters were already replaced by `?` before reaching Nevis (an encoding problem in the sending app) is refused with a clear message instead of saving a broken page.
- **Settings.** Controls next to each other in a row now have a gap.

## Under the hood

- Backup code is split into `backup/` (shared format, checking without writing, browser and desktop drivers).
- New design-system parts: `Facts` and `Notice`.
- The font choice is composed in one place (`fontStack.ts`), with tests.

## Downloads

- Windows: EXE setup.
- macOS: universal DMG for Apple Silicon and Intel Macs.

## Existing workspaces

Your existing vaults, notes, attachments, and settings remain compatible. If you had an English font chosen as your only font, it becomes your English font and Persian letters use the default Persian font.
