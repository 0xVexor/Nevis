# Nevis 1.1.0 beta 7

A pre-release for testing. It is not offered as an update unless **Receive pre-release updates** is turned on in Settings → About → Updates.

## What's new

Everything in 1.1.0 beta 6, plus:

- **Change your shortcuts.** In Settings → Shortcuts you can now change the keys for search, the sidebar, reader mode, the text column width and find in page. A key that cannot be told apart from typing, or that another action already uses, is refused, and each shortcut can be reset.
- **Search reaches every feature.** The search (Ctrl+K) now has a command for every settings page, restore from backup, check for updates, find in page, version history and print. Shortcut hints show the keys you chose.

## Fixes

- **Ctrl+F with the Persian keyboard.** Find in page now works while the system layout is Persian.
- **Esc closes only the search.** Pressing Esc in the search or the find bar no longer also leaves reader mode or closes the page panel.

## Downloads

- Windows: EXE setup.
- macOS: universal DMG for Apple Silicon and Intel Macs.

## Existing workspaces

Your existing vaults, notes, attachments, and settings remain compatible.
