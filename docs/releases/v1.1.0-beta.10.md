# Nevis 1.1.0 beta 10

A pre-release for testing. It is not offered as an update unless **Receive pre-release updates** is turned on in Settings → About → Updates.

## What's new

Everything in 1.1.0 beta 9, plus:

- **The table menu in the editor toolbar** now opens like every other menu, with the same motion and keyboard handling. Pick a table size with the arrow keys and press Enter, or hover the grid as before.

## Fixes

- **Timeline:** a bar moves as soon as its dates change, instead of staying in its old place until a row is added or removed.
- **Feed and Board:** after a search, the pages shown load their content (and the "first image in the page" preview) even when the number of results stays the same.
- **Typing in a page** no longer rebuilds every toolbar button on each keystroke, so the toolbar keeps its focus and hover state and typing in long pages stays smoother.

## Downloads

- Windows: EXE setup.
- macOS: universal DMG for Apple Silicon and Intel Macs, and a PKG.

## Existing workspaces

Your existing vaults, notes, attachments, and settings remain compatible.
