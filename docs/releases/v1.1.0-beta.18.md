# Nevis 1.1.0 beta 18

A pre-release for testing. It is not offered as an update unless **Receive pre-release updates** is turned on in Settings → About → Updates.

## Fixes

- **Block moving animates again in the app.** In 1.1.0 beta 17 the installed app played the move animations so fast they could not be seen: a dropped block now slides from where it was to where it lands, a cancelled move sends its card back, and the drop preview fades between a line and columns, as intended.
- **Deleting a whole page with columns removes the columns too.** Selecting everything and deleting it, or typing over it, now leaves an empty page instead of empty columns.
- **Empty columns can be removed.** Backspace or Delete in a layout whose columns are all empty removes the layout.

## Downloads

- Windows: EXE setup.
- macOS: universal DMG for Apple Silicon and Intel Macs, and a PKG.

## Existing workspaces

Your existing vaults, notes, attachments, and settings remain compatible.
