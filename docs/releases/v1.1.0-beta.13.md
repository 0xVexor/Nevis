# Nevis 1.1.0 beta 13

A pre-release for testing. It is not offered as an update unless **Receive pre-release updates** is turned on in Settings → About → Updates.

## Fixes

Everything in 1.1.0 beta 12, plus:

- **Sidebar button in the top bar for the icon sidebar.** With the icon-only sidebar style, the button that opens and closes the sidebar was on the sidebar itself. It is now in the top bar, before the back and forward arrows, as in the other sidebar styles.

## Downloads

- Windows: EXE setup.
- macOS: universal DMG for Apple Silicon and Intel Macs, and a PKG.

## Existing workspaces

Your existing vaults, notes, attachments, and settings remain compatible.
