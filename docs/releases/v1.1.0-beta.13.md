# Nevis 1.1.0 beta 13

A pre-release for testing. It is not offered as an update unless **Receive pre-release updates** is turned on in Settings → About → Updates.

## New

Everything in 1.1.0 beta 12, plus:

- **A new sidebar.** Navigation is a slim rail of icons, and each view has its own side panel next to it: the page tree with Expand all, Collapse all and Reveal current note on Home and in notes, sources and projects in Tasks, and the categories in Settings. The panel can be resized and hidden; Ctrl+B shows or hides it outside text editing, and Ctrl+, opens Settings.
- **Icon-only sidebar by default.** Nevis starts with the icon rail unless you already have saved settings, which keep your sidebar style. A click on the logo opens it with labels, and a click elsewhere folds it back. Hovering, or using an icon such as New, no longer opens it. You can change the style in Settings → Appearance → Sidebar style.
- **Easier column resizing in tables.** The border between two columns is easier to grab and shows a guide line. Dragging it moves width from one column to the other, so the table keeps its size. The table's end border resizes the last column. Columns can no longer be squeezed to a sliver, and a double-click on a border makes all columns even again.
- **Expand the selection with Ctrl+W.** Each press selects more: the word, the sentence (a line in code), the paragraph, the surrounding block, then the page. You can change the key in Settings → Shortcuts.

## Fixes

- **Tables fill their frame.** After resizing columns, a table could leave an empty area inside its frame. The frame now fits the table.
- **The table toolbar stays open.** Clicking a button on the table toolbar closed the toolbar.
- **The code language menu opens where you click.** Choosing a language for a code block (such as Auto-detect) opened the list at the bottom of the page and pushed the page down. It now opens next to its button.
- **Tab in code blocks adds four spaces.** It no longer jumps to the next column stop, which could add a single space in the middle of a line.
- **Ctrl+A in a code block selects the block.** The first Ctrl+A selects only the code; press it again to select the whole page.
- **No look-alike sidebar icon next to Home.** The Home breadcrumb showed the sidebar icon, so it looked like a second sidebar button. It now shows just the word.
- **A smaller template preview.** The preview on the Templates page no longer runs to the bottom of the window.
- **Flashcards** no longer overlap, and long breadcrumbs are shortened instead of overflowing.
