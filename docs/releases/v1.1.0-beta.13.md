# Nevis 1.1.0 beta 13

A pre-release for testing. It is not offered as an update unless **Receive pre-release updates** is turned on in Settings → About → Updates.

## Fixes

Everything in 1.1.0 beta 12, plus:

- **Sidebar button in the top bar for the icon sidebar.** With the icon-only sidebar style, the button that opens and closes the sidebar was on the sidebar itself. It is now in the top bar, before the back and forward arrows, as in the other sidebar styles.
- **No look-alike sidebar icon next to Home.** The Home breadcrumb showed the sidebar icon, so it looked like a second sidebar button. It now shows just the word.
- **The code language menu opens where you click.** Choosing a language for a code block (such as Auto-detect) opened the list at the bottom of the page and pushed the page down. It now opens next to its button.
- **Tab in code blocks adds four spaces.** It no longer jumps to the next column stop, which could add a single space in the middle of a line.
- **Ctrl+A in a code block selects the block.** The first Ctrl+A selects only the code; press it again to select the whole page.

- macOS: universal DMG for Apple Silicon and Intel Macs, and a PKG.
