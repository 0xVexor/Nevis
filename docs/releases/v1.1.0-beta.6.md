# Nevis 1.1.0 beta 6

A pre-release for testing. It is not offered as an update unless **Receive pre-release updates** is turned on in Settings → About → Updates.

## What's new

Everything in 1.1.0 beta 5, plus:

- **Choose where a backup goes.** When you restore a backup in the desktop app, you now pick: a new workspace next to the current one (named like the backup's own workspace, and you can rename it), or this workspace. Restoring into this workspace writes the backup's pages, files, databases and history into it, replaces a page that exists in both with the backup's version and deletes nothing. A copy of the workspace is saved next to it first, so it can always be undone.
- **A clearer message for a desktop backup in the browser.** If you open a backup made by the desktop app in the browser version, you are told it can only be restored in the desktop app.

## Under the hood

- New design-system layout part: `ds-stack`.
- Desktop restore takes a target and a name; tests cover both.

## Downloads

- Windows: EXE setup.
- macOS: universal DMG for Apple Silicon and Intel Macs.

## Existing workspaces

Your existing vaults, notes, attachments, and settings remain compatible.
