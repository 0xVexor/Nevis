# Nevis 1.2.0 beta 1

A pre-release for testing. Final releases stay on the stable channel; this version reaches only people who enable pre-release updates in Settings → About → Updates.

## What’s new

- **GIF and video.** Add GIFs and videos to a page. Videos play in the editor and appear in exports.
- **Smaller media, same look.** PNG pictures are stored as lossless WebP, JPEG and WebP at high quality, large videos are re-encoded to H.264, and animated GIFs become short looping videos. A result that is not clearly smaller is not used; the original is kept. Turn it off with Settings → Compress images and videos.
- **Save As for exports.** In the desktop app, Markdown, whole-workspace zip, database and chart exports ask where to save. Cancelling saves nothing.
- **Start animation.** The logo draws itself and fades into the app. It is skipped when Reduce motion is on.

## Please test

- Adding a large video and a long GIF in the desktop app, on Windows and macOS. If the system cannot encode H.264, the original file is stored.
- The Save As dialog for every export type.
- Printing or exporting a page with a video: a video does not appear in a printed PDF.

## Existing workspaces

Existing vaults, notes and attachments keep their formats. Media added before this version is not changed.
