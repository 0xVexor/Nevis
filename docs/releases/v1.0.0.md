# Nevis 1.0.0

The first public stable release of the current Nevis app, built from the latest development and sync-settings updates.

- Windows installer and universal macOS installer for Apple Silicon and Intel.
- Notes remain in workspace folders on the computer; sync is optional and uses https://nevis.manaz.pro by default.
- Sign in or create an account from the start screen, open local workspaces, or download them from the server.
- Independent block edits merge automatically. Conflicting edits stay recoverable and can be reviewed and resolved on the page.
- Clearer workspace lists, connection state, server trash controls and confirmation before syncing with another account or server.
- Updated server API for the latest workspace and trash actions.

Automatic migration to experimental Yjs page states remains disabled.

This version restarts numbering at 1.0.0 after internal beta testing. Install it manually over any 1.2.0 beta build; those builds consider 1.0.0 a lower version. Close Nevis before installing. Existing workspace folders are retained; keep a backup before replacing a test build.
