# Nevis 1.0.0

The first stable Nevis release brings pages, databases, drawings and tasks together in one local workspace.

## What's new

- A complete database workspace: tables, boards, lists, calendars, timelines, charts, forms, maps and dashboards, with properties, relations, formulas, filters, sorting, grouping and workflows.
- A refreshed Home page with quick creation actions, workspace collections, recent and pinned pages, and offline landscape backgrounds that follow the time of day.
- A larger, faster template gallery with centered incomplete rows.
- Consistent database controls, clearer validation messages, full-size cell editors and a redesigned location editor.
- Horizontal scrollbars with a shared design, including an accessible Pages rail in tree and compact views while scrolling through a long list.
- Database tables follow the page's vertical scrolling, and row previews and menus open in the correct layer.
- Platform-aware shortcut labels on macOS, improved RTL flow arrows in Persian prose and more room around block drag handles.
- The Nevis name throughout the app and installers, with an accent-colored full stop in the app wordmark.

## Downloads

- Windows: EXE setup or MSI installer.
- macOS: universal DMG for Apple Silicon and Intel Macs.

## Existing workspaces

Your existing vaults, notes, attachments, and settings remain compatible. The app keeps its existing storage identity so upgrading does not create an empty workspace.

## Development

`dev` is the development branch. Final releases reach `main` through a release pull request and are published only after both installer builds complete.
