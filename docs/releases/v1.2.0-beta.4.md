# Nevis 1.2.0 beta 4

Beta installers for Windows and macOS, using https://nevis.manaz.pro as the default sync server.

- Fix downloading a previously synced workspace into a new folder on the same computer. The new folder starts with its own baseline, so files absent from that folder are downloaded instead of being treated as deletions on the server.
- Older saved sync states are read safely. The first run with this version establishes the local folder before interpreting deletions.
- Enable sync for each workspace separately. Automatic sync runs for the workspace currently open.
- Sign in on another device and download the workspace into a new empty folder.

A regression test reproduced the original issue before the fix. The sync engine tests pass after the change. Keep a workspace backup while testing this beta, and close other running copies of Nevis.

Windows has a setup executable. macOS supports Apple Silicon and Intel Macs.
