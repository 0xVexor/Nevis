# Nevis 1.2.0 beta 7

Windows and universal macOS beta installers using https://nevis.manaz.pro.

- Includes the latest onboarding/sign-in, page-conflict, sync-finish, sync-hardening and sync-blocker changes.
- Merge independent edits to different blocks automatically. Conflicting edits are recorded durably and can be reviewed and resolved on the page.
- Show sync state in the sidebar and held deletions, skipped files and server trash in settings.
- Preserve deletion history through downloads, restores and upgrades; keep newer content and recoverable copies during conflicts.
- Update server snapshot deletion history, upload quotas, transfer deadlines, and password-confirmed workspace trash controls.

Automatic migration to Yjs page states remains disabled by the existing release flag. The updated server must be deployed before using these clients. Workspace data and accounts are retained by the update.

Enable sync for each workspace. Close other copies of Nevis before installing. Keep a local backup while evaluating this beta.
