# Nevis 1.1.0

Nevis 1.1.0 brings the improvements tested across the 1.1 beta series into the stable desktop release.

## Notes and workspace

- Flexible editor columns and block layout controls, with visible move animations and cleaner removal of empty columns.
- Updated workspace navigation, compact page lists, side panels, settings, templates, and standard appearance controls.
- Editor, drawing, database, printing, and Persian/right-to-left improvements accumulated through beta 18.
- Local MCP document tools with explicit connection permissions. These work with the open desktop app and remain separate from cloud accounts or server synchronization.

## Release boundaries

- Slide decks are disabled in this release. Their creation controls, templates, navigation, MCP tools, and native slide export are unavailable.
- The slide implementation and storage format remain in the source. Existing deck data is retained in vaults and full backups; disabling the feature does not convert or delete it.
- Named appearance presets, including Forest & Lime, are disabled. Standard light, dark, and system appearance remain available. Saved preset choices are preserved but render with the standard appearance.
- Browser sign-in, email OTP accounts, document sharing, and the new Gin/Yjs/Hocuspocus server integration are not included. Nevis continues to work locally without an account.

## Existing workspaces

Existing vaults, notes, attachments, settings, and local document permissions retain their existing formats. No cloud enrollment or account migration runs during this update.

## Release preparation

This version is prepared on `dev` for a pull request into `main`. Installers and a GitHub Release are published by the normal signed-update workflow only after the release pull request is merged and the matching tag is created on `main`.
