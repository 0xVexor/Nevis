# Nevis 1.1.0

The first final release of the 1.1 series. It includes everything from the 1.1.0 betas and a new look for the whole app.

## What's new

- **One design for every screen.** Home, pages, databases, templates, tasks, flashcards, drawings, the graph, all pages, files, trash, sharing, updates and Settings are built from the same parts, in the same sizes, corners, spacing and colors. The old styles are gone, so a change to the look now reaches the whole app.
- **A new toolbar for tables and images.** The table and image tools are one clean row of icons with a tooltip on each, the same in the editor, the zoom viewer and the diagram bar.
- **Menus, dialogs and settings that behave the same everywhere.** The `/` menu, right-click menus, dialogs, search fields and the sections that open and close share one design and the same keyboard handling. Settings rows, the Backup card and Connections use the same rows.
- **Databases on the new design.** A list beside a preview, one bar with the views as tabs and one toolbar, panels for filter, sort, group and properties, a live preview next to the form builder and the chart settings, and one context menu for rows, cards and list lines with Undo on delete.
- **Templates, Tasks, Flashcards, Drawings, Graph and All pages redesigned.** A live preview of the page a template creates, tasks grouped by source, a flashcard session that starts with today's cards, the last drawing shown large, a calmer map, and a table that keeps its columns when pages have many tags.
- **Import an Obsidian folder** by dropping it on the import area.
- **Easier to drag blocks and columns.** The targets are larger and easier to aim at.
- **A new first launch and first note**, with the new brand.
- **Desktop:** a custom title bar, a Windows installer with its own images, and a new installer for macOS.

## Fixes

- **Opening a workspace that still used the old metadata folder** no longer fails on Windows ("Access is denied").
- **Persian titles and excerpts** on Home, in the timeline and in calendar events follow their own direction.
- **Narrow windows:** the top bar keeps its Share button inside the window, the dashboard stacks to one column and the view tabs scroll sideways.
- **Pop-ups no longer hide behind each other.** Menus and toolbars open above dialogs, and toasts above both.
- **The CSV import maps the title column to the title**, and calendar day numbers are no longer hidden under events.
- The AI relay opens Nevis only for a real tool call.

## Things to know

- Pre-release updates are separate. This is a final release: it is offered to everyone and replaces the 1.1.0 betas.
- The backup folder format is desktop only. The browser still writes a single JSON file.

## Downloads

- Windows: EXE setup.
- macOS: universal DMG for Apple Silicon and Intel Macs, and a PKG.

## Existing workspaces

Your existing vaults, notes, attachments, and settings remain compatible. A workspace that still uses the old metadata folder is upgraded when it is opened.
