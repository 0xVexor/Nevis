# Nevis 1.2.0 beta 6

Windows and universal macOS beta installers using https://nevis.manaz.pro.

- Rebuild the cloud mirror with paginated snapshots while preserving local deletion history when older server history expires.
- Protect newer notes when an older copy of a workspace is restored; retain conflicting content in history.
- Keep missing folders and unconfirmed file removals from deleting cloud files. Fresh downloads keep a fresh local baseline.
- Coordinate downloads with local saves and clear obsolete deletion markers when a file returns.
- Include page-state merging support and its server capability. Automatic migration to page states remains disabled by the repository release flag.
- Fix repeated local saves and page-state deletion locking.
- Preserve the sync baseline across upgrades and hold only unconfirmed deletions when the rest of a round is safe.
- Strengthen server blob validation and coordinate background cleanup with uploads and commits.

The sync server must be updated before using this release. Existing accounts and workspace data are retained.

Enable sync for each workspace. Automatic sync runs for the currently open workspace. Close other copies before testing. Keep a local workspace backup while evaluating this beta.
