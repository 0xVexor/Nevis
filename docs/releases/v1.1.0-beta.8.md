# Nevis 1.1.0 beta 8

A pre-release for testing. It is not offered as an update unless **Receive pre-release updates** is turned on in Settings → About → Updates.

## What's new

Everything in 1.1.0 beta 7, plus:

- **One Backup card.** In Settings → Data, choosing a folder, backing up now, turning automatic backup on or off and the single-file backup are in one place, with the time of the last backup and how many pages, folders and images it holds. Back up now works even when automatic backup is off.
- **A backup folder for each workspace (desktop).** A workspace is backed up into its own folder, named after the workspace and its id, so two workspaces never overwrite each other. Each page is its own file, only changed files are written, and every file is checked after it is written. Because pages are separate files, a backup folder kept in Git or a synced folder changes only by the pages that changed.
- **Merge a backup into this workspace.** Restoring has a new default, *Merge into this workspace*. Pages that are not here are added, a page in both keeps its newer version (the older one goes to the page history), database pages merge cell by cell, pages in your trash stay there, and nothing is deleted. A copy of the workspace is saved next to it first, and merging the same backup again changes nothing. *A new workspace* and *Replace in this workspace* are still there.
- **Restore from a backup folder.** Pick the workspace's folder inside your backup folder and review what is in it before anything changes.
- **A safer backup.** If a workspace suddenly has far fewer pages than its last backup, the backup is not overwritten until you choose *Back up anyway*.

## Fixes

- **The day's backup file is the day's last state.** In the browser, the dated backup file used to be written once, with the first backup of the day, and then left as it was. It is now rewritten with every backup.
- **Markdown export is described as what it is.** It is for reading and moving pages, not a backup: databases, history and settings are not in it.

## Things to know

- The backup folder format is desktop only. The browser still writes a single JSON file.
- The desktop app no longer keeps dated copies in the backup folder. If you want a history, keep the folder in Git or a synced folder.
- The previous automatic backup setting on desktop is not carried over; choose the folder once more.
