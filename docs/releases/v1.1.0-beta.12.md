# Nevis 1.1.0 beta 12

A pre-release for testing. It is not offered as an update unless **Receive pre-release updates** is turned on in Settings → About → Updates.

## Fixes

Everything in 1.1.0 beta 11, plus:

- **Pages no longer slide under the sidebar.** Moving through a page with Tab could shift the whole screen to the side, behind the sidebar. It now stays in place.
- **Drawings open with what you drew.** A board opened again from Drawings could show an empty canvas even though it was saved. It now opens with its latest drawing.
- **One tool bar on the drawing canvas.** In a narrow window a second tool bar appeared over the drawing tools. Only Nevis's own tool bar is shown now.
- **Tab stays in the page.** While writing, Tab no longer moves the focus out of the page. Lists and tables still use Tab as before; elsewhere it types a tab.

## New

- **Triangle** in the drawing tools, and the tools in a new order with number keys: 1 text, 2 line, 3 arrow, 4 draw, 5 rectangle, 6 diamond, 7 ellipse, 8 triangle, 9 image, 0 eraser.
- **Page text size from the keyboard.** Ctrl + / Ctrl − (or Ctrl and the mouse wheel) make the page text bigger or smaller; Ctrl 0 goes back to normal. It is the same setting as Settings → Text size.
- **A new line on Home.** The line under the greeting changes with the time of day, picked from 50 short prompts.

## Downloads

- Windows: EXE setup.
- macOS: universal DMG for Apple Silicon and Intel Macs, and a PKG.

## Existing workspaces

Your existing vaults, notes, attachments, and settings remain compatible.
