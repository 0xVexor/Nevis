# Nevis 1.1.0 beta 1

A pre-release for testing. It adds AI app connections and is not offered as an update unless **Receive pre-release updates** is turned on in Settings → About → Updates.

## What's new

- **Connect an AI app once.** Settings → AI connection has one **Allow AI access** switch and a separate **Allow document editing** switch. One button each sets up Claude Desktop, ChatGPT / Codex and Gemini CLI, and **Copy for another AI** covers other apps. After a restart of the AI app there is nothing to copy again; Nevis opens by itself when an AI app asks for it.
- **Documents.** AI apps can list, search, read, create and edit pages, change page details, read history and undo their own edits. Pages can be created from Markdown and Markdown can be inserted into an existing page.
- **Databases.** AI apps can list, describe and read databases, create a database with properties and rows, and add rows to an existing database.
- **You stay in control.** AI apps see only what you allow, hidden pages stay hidden (Advanced), editing is off by default and edits can be undone.
- Pages saved by older versions as plain HTML can now be read by AI apps.
- If a workspace cannot be opened, Nevis now shows a message instead of a blank page.

## Known limits

- Drawings and diagrams are not available to AI apps.
- AI apps cannot yet edit or delete existing database rows, or change properties and views.
- Tested with Claude Desktop on Windows. Codex, Gemini CLI and macOS have not been tested on a real machine yet; please report what you find.

## Downloads

- Windows: EXE setup or MSI installer.
- macOS: universal DMG for Apple Silicon and Intel Macs.

## Existing workspaces

Your existing vaults, notes, attachments, and settings remain compatible.
